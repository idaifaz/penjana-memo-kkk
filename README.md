# Penjana Memo KKK

Web app satu halaman untuk menjana memo rasmi dan minit mesyuarat Kolej Komuniti Kuantan dalam format Word (.docx). Dua tab: Memo dan Minit mesyuarat, masing-masing dengan pratonton.

Isi tarikh, nama program, tempat dan agenda, pilih staf untuk lampiran, kemudian tekan **Jana memo (.docx)**.

- Fail Word dijana terus dalam browser (JSZip). Tiada data dihantar ke mana-mana server.
- Senarai staf dan tetapan disimpan dalam localStorage browser.
- Ruj. Fail dibiarkan kosong untuk diisi manual.

Buka: https://idaifaz.github.io/penjana-memo-kkk/
